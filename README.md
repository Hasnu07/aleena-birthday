# Happy Birthday Aleena

A birthday website for Aleena: Real Madrid x McLaren, Bellingham x Piastri, a sticker pack, a photo gallery, a letter, and a race she has to win.

Static site: `index.html`, `css/style.css`, `js/main.js` (intro, confetti, gallery, candles) and `js/race.js` (Aleena Grand Prix mini-game). Stickers were generated with Higgsfield.

Run locally with any static server, for example:

```
python -m http.server 8765
```
